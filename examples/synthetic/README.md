# Ejemplos sintéticos / Synthetic examples

> Todos los datos mostrados en este repositorio son ficticios y se utilizan exclusivamente con fines de demostración profesional.
> All data shown in this repository is fictional and used exclusively for professional portfolio demonstration purposes.

Estos archivos ilustran el **tipo de dato** que la experiencia presenta y que el
pipeline de captación acepta. No son fixtures del producto real ni derivan de
propiedades, precios o personas reales.

- `sample-property.json` — residencia ficticia del desarrollo inventado
  "Residencial Mirador Azul" (Mallorca): precio, superficie, habitaciones y
  prestaciones ilustrativas.
- `sample-lead.json` — envío ficticio del formulario de contacto con la forma
  validada por la API (nombre, email, teléfono, presupuesto, interés, mensaje)
  y sus campos de atribución (UTM, referrer, dispositivo).

Notas:

- Los nombres, lugares, precios, cifras, correos y teléfonos son inventados.
- El formato exacto de los datos del producto real es más amplio;
  estos ejemplos son solo ilustrativos.
