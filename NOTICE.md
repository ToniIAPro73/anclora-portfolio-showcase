# Portfolio notice

This repository presents a reduced case study of the Anclora Portfolio project
— a demonstration piece built to showcase premium real-estate product design
and engineering capability under the Anclora Private Estates visual identity.

The operational source code is maintained separately and is not distributed
through this public repository.

The public material intentionally excludes:

- production source code;
- API implementation and rate-limiting logic;
- lead-capture backend and persistence layer;
- analytics/conversion-tracking implementation;
- infrastructure and deployment configuration;
- real commercial, customer or property information.

All properties, prices, investment figures and commercial content are
fictional and intended solely to demonstrate software architecture and
product-development experience.
